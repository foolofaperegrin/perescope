Unreal Engine 5.5

Hoot

Space invaders for owls. Unreal Engine 5.4. Primarily an art-pipeline experiment with procedurally-generated assets using Blender’s Geometry Nodes, rendered into 2D sprites using a pixel-art EVEE shader and a dark, moonlit bruise-punk aesthetic.

Demonstrating a few Blender objects used to generate 2D pre-rendered sprites for use in Hoot (Unreal Engine 5.5)

Buildings: Geometry Node setup instances a base mesh upon itself recursively, the result is arrayed around an axes offset.

Landscape: Geometry nodes turns points into volumes, remeshes and applies noise, voronoi textures and more to get a lumpy rocky look that can be moved into position, sculpted like clay.

Trees: Geometry nodes take an input curve to build a cylinder mesh which is then peturbed to give an organic look. Radially-arrayed "crown" meshes are instanced at line end.

Shader: Pixel Art (EVEE) by Lucas Roedel

The player owl must protect a gargantuan rotting carcass from waves of aerial drones by tossing them into one another, creating chain reactions. The owl must perch upon parts of the carcass and “Hoot” to reveal yummy critters, catch them, and feed these to her chicks. If all three chicks die, the game is over.

Levels are generated randomly by spawning environment sprites upon one another.
